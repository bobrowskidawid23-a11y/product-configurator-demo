# Product Configurator Demo

Publiczne demo konfiguratora produktu z walidacją wymiarów, doborem komponentów i wyceną netto/brutto. Wszystkie produkty, kody i ceny są syntetyczne — projekt nie zawiera kodu ani danych pracodawcy.

## Co pokazuje

- rozdzielenie logiki biznesowej od interfejsu,
- walidację reguł i bezpieczne odrzucanie nieobsługiwanych wariantów,
- responsywny i dostępny formularz,
- testy jednostkowe wbudowanym runnerem Node.js.

## Uruchomienie

Otwórz `index.html` przez lokalny serwer HTTP, np. rozszerzenie Live Server. Testy:

```bash
npm test
```

## Technologie

HTML, CSS, JavaScript ES Modules, Node.js Test Runner.
